大模型强化学习的几何优化偏置

文章核心解读

https://arxiv.org/pdf/2511.08567

  • 问题： 为什么 RLVR 这种计算成本极高、效果又好的训练方法，最终只对模型参数做了微乎其pre的、稀疏的修改？
  • 错误线索： 以为“稀疏性”本身是原因或目标。
  • 真相： 稀疏性只是一个表象。其背后隐藏着一个由预训练模型自身结构决定的“优化偏置”。
  • 理论解释： 作者提出了“三门理论”来解释这个偏置是如何产生的。
  • 启示： 既然 RL 和 SFT 的优化路径（作案手法）完全不同，那么为 SFT 设计的工具（如某些 PEFT 方法）不应该直接用于 RL，否则会适得其反。

分段解读

1. 揭示问题：从“稀疏”表象到“优化偏置”本质

这部分首先澄清了事实，然后提出了更深层次的发现。

  • 事实澄清： 作者先指出，之前大家观察到的“稀疏性”可能因为测量方法不准（忽略了 bfloat16 低精度浮点数的特性）。他们用一个更精确的动态阈值重新测量，确认了 RLVR 的参数更新确实比 SFT 稀疏得多，但数值没以前报告的那么极端。
  • 核心发现： 最关键的发现是，这些稀疏的更新并非随机发生。通过对比不同数据集、不同 RL 算法训练的同一个模型，作者发现参数更新总是发生在相似的位置（Jaccard 相似度很高）。这说明，优化的路径似乎是被预训练模型“内定”好的，这就是所谓的“模型条件优化偏置”。

一句话总结： RLVR 的参数更新不仅少，而且非常有规律，总是倾向于修改同一批参数，这个规律是由模型本身决定的。

2. 核心理论：“三门理论”

为了解释这个“优化偏置”从何而来，作者提出了一个三步走的模型，像是一个过滤器：

  1. 第一道门：KL 散度 (范围门)
    • 作用： 约束。
    • 解释： RLVR 是在线策略（on-policy）学习，不能让新模型和旧模型差别太大，否则训练会不稳定。KL 散度就像一个“缰绳”，确保每一步更新都不能迈得太大，只能在当前位置附近小范围探索。
    • 结果： 参数更新的幅度很小。但这只解释了“为什么变化小”，没解释“变化发生在哪里”。
  2. 第二道门：模型几何 (路径选择门 - 理论核心)
    • 作用： 引导。
    • 解释： 预训练好的模型，其参数空间不是一片平地，而是有“山峰”有“平原”的复杂地形。
      • 高曲率区域（山峰）： 代表模型学到的核心、稳定知识。稍微改动这里，模型行为就会剧变（就像在山脊上走，一步踏错就掉下悬崖）。作者认为“主权重”（Principal Weights）就处于这些区域。
      • 低曲率区域（平原）： 代表模型的冗余空间，修改这里的参数对模型核心功能影响不大，提供了安全的调整空间。
    • 核心假设： 在 KL 散度的“小范围”约束下，RL 更新会主动规避那些陡峭的“高曲率山峰”，而被引导到平坦的“低曲-率平原”上。这样做最安全、最高效。
  3. 第三道门：浮点数精度 (显现门)
    • 作用： 过滤。
    • 解释： 经过第二道门的引导，优化器其实想对所有参数都做更新。但在“平原”区域，更新幅度较大，超过了 bfloat16 的精度阈值，所以被记录下来。而在“山峰”区域，模型只敢做极其微小的调整（sub-ULP），这些微小变化因为精度不够，在存储时被直接“四舍五入”掉了，看起来就像没变一样。
    • 结论： 我们看到的“稀疏性”，是优化偏置（第二道门）和有限精度（第三道门）共同作用的结果。精度是放大器，而非根本原因。

一句话总结： RL 更新先被 KL 散度限制了步子大小，然后被模型自身的几何结构引导到“安全”的路径上，最后因为精度问题，只有在“安全”路径上的更新才被实际记录下来，从而表现出稀疏性。

3. 实验验证

作者通过一系列巧妙的实验来证明“三门理论”，特别是第二道门“模型几何”的正确性。

  • 谱几何分析： 证明 RLVR 倾向于保持模型的谱结构稳定（在平原上走），而 SFT 则会剧烈改变它（推倒山峰）。
  • 更新位置分析： 证明 RLVR 的更新位置与“主权重”（高曲率山峰）的重合度显著低于随机，而 SFT 恰恰相反。这直接说明 RL 在“躲着”重要参数走。
  • 因果干预实验： 通过随机旋转打乱模型某几层的几何结构（相当于把地形图打乱），发现这些层的更新模式就从有规律变成了随机。这证明了模型几何结构是导致优化偏置的直接原因。

4. 实践启示与警告

这部分是论文最有价值的地方，它告诉我们这个理论发现如何指导实践。

  • 核心论点： SFT 和 RL 的优化路径在根本上是背道而驰的。SFT 倾向于修改“主权重”，而 RLVR 倾向于规避它们。
  • 案例一（稀疏微调）： 实验表明，如果强制 RL 只更新“主权重”，学习效率会极低。反之，如果只更新 RL 偏好的“非主、低幅值”权重（安全区域），效果几乎和全参数微调一样好。这为设计高效的 RL 稀疏微调提供了思路。
  • 案例二（LoRA vs PiSSA）：
    • LoRA 在 RL 中效果好，是因为它的低秩更新天然地契合了 RL 在“低曲率平原”上进行微调的特性。
    • PiSSA 是为 SFT 设计的，旨在更精确地对齐和修改“主权重”。把它用在 RL 上，相当于强迫 RL 去爬它正在极力规避的“山峰”。结果是，PiSSA 在 RL 中不仅没有优势，反而更容易在学习率较高时崩溃。

最终警告： 不要想当然地把 SFT 领域的“最佳实践”（Best Practices）和参数高效微调方法（PEFT）直接搬到 RL 领域。为 RL 设计 PEFT 必须考虑其独特的、由模型几何驱动的优化动态。

问题解答：模型谱结构 (Model Spectral Structure) 是什么？

这是一个线性代数的概念，但在大模型背景下，我们可以用一个更直观的方式来理解它。

1. 简单类比：

想象一个复杂的建筑结构，比如一座大厦。 * 承重墙和主梁： 这些是建筑的核心骨架，决定了建筑的稳定性和基本形态。动了它们，大厦可能就塌了。 * 非承重墙、门窗、装修： 这些是次要结构，可以在不影响主体安全的情况下进行修改、移动或替换。

“模型谱结构”就类似于这座大厦的“核心骨架蓝图”。

2. 技术解释：

  • 模型由权重矩阵构成： 大语言模型内部有大量的权重矩阵（Weight Matrix），每个矩阵都负责一种线性变换。
  • 矩阵的谱（Spectrum）： 在线性代数中，一个矩阵的“谱”通常指它的奇异值（Singular Values）和奇异向量（Singular Vectors）的集合。（通过奇异值分解 SVD 得到）。
    • 奇异值 (Singular Values)： 可以理解为每个变换方向的“重要性”或“强度”。大的奇异值对应着上面比喻中的“主梁”，是矩阵变换中最主要、最强的部分。
    • 奇异向量 (Singular Vectors)： 定义了这些变换的“方向”。它们是“主梁”的朝向。
  • 模型谱结构： 就是模型中所有（或关键）权重矩阵的奇异值和奇异向量共同构成的结构。它揭示了模型内部计算的主次关系和核心功能方向。一个训练好的模型，其谱结构包含了它从海量数据中学到的核心知识模式。

3. 在这篇文章中的意义：

  • 保持谱结构（RLVR）： RLVR 的更新非常保守，它不怎么改变大的奇异值和它们对应的方向。就像装修队只在非承重墙上刷漆、换窗户，但绝不动承重墙。这保证了模型的核心知识和稳定性不被破坏。
  • 扭曲谱结构（SFT）： SFT 为了拟合特定的“指令-回答”数据，会更激进地改变模型。它会显著改变奇异值和奇异向量。就像为了改建，不惜敲掉承重墙，重塑建筑结构。这虽然能实现新功能，但也可能损害模型的泛化能力和原始知识。

总结一下： 模型谱结构是描述模型内部权重矩阵核心功能强度与方向的数学蓝图。这篇文章的核心发现之一就是，RLVR 倾向于尊重和保持这个蓝图，而 SFT 则会大刀阔斧地修改它。
