上文已经提到了Pass@k 奖励对奖励函数的塑形，这里分析下其特性，并给出探索的一些其他特性隐式奖励函数。

. 分析Pass@k 奖励分布特性

  1. 对称性：原始 Pass@1 的 0/1 奖励，优势函数 A_p(p) 和 A_n(p) 的图像关于点 (1/2, 0) 呈中心对称？
  2. 无偏性：Pass@k 的解析解，其期望是否无偏（unbiased）？
  3. 方差：Pass@k 解析解的优势估计，方差是否较大？

下面将分步进行严谨的推导和论证。

1. Pass@1 优势的“对称性”问题

在标准的 Pass@1 训练中，对于一个 rollout，我们得到 \(N\) 个答案，其中 \(N_p\) 个正确，\(N_n\) 个错误。我们通常将每个答案视为一次独立的伯努利试验，其成功概率为 \(p = N_p / N\)。

  • 奖励 (Reward): 正确答案 \(r=1\)，错误答案 \(r=0\)。
  • 平均奖励 (\(\mu\)): \(\mu = p \cdot 1 + (1-p) \cdot 0 = p\)。
  • 奖励标准差 (\(\sigma\)): \(\sigma = \sqrt{p(1-p)}\)。

根据常用的优势标准化定义 \(A = (r - \mu) / \sigma\)：

  • 正确答案 (Positive Response) 的优势 \(A_p\): \[A_p = \frac{1 - \mu}{\sigma} = \frac{1 - p}{\sqrt{p(1-p)}} = \sqrt{\frac{(1-p)^2}{p(1-p)}} = \sqrt{\frac{1-p}{p}}\]
  • 错误答案 (Negative Response) 的优势 \(A_n\): \[A_n = \frac{0 - \mu}{\sigma} = \frac{-p}{\sqrt{p(1-p)}} = -\sqrt{\frac{p^2}{p(1-p)}} = -\sqrt{\frac{p}{1-p}}\]

对称性分析： 根据中心对称的数学定义，若函数 \(f(x)\) 与 \(g(x)\) 的图像关于点 \((a, b)\) 中心对称，则它们必须满足关系：\(g(2a-x) = 2b - f(x)\)。

我们将此定义应用于我们的优势函数： * 令 \(f(p) = A_p(p)\)， \(g(p) = A_n(p)\)。 * 对称中心点为 \((a, b) = (1/2, 0)\)。

我们需要验证的等式是：\(A_n(2 \cdot \frac{1}{2} - p) = 2 \cdot 0 - A_p(p)\)，即 \(A_n(1-p) = -A_p(p)\)。

我们分别计算等式的左右两边： * 左边: 将 (1-p) 代入 \(A_n(p)\) 的表达式中： \[A_n(1-p) = -\sqrt{\frac{1-p}{1-(1-p)}} = -\sqrt{\frac{1-p}{p}}\] * 右边: 对 \(A_p(p)\) 取负： \[-A_p(p) = -\sqrt{\frac{1-p}{p}}\]

由于左边 = 右边，等式成立。这证明了两个优势函数图像确实关于点 (1/2, 0) 呈中心对称。

很明显 \[ A_p = \sqrt{\frac{p_w^k}{1-p_w^k}} \]

\[ A_n = (1 - p_w^{k-1}) \sqrt{\frac{p_w^k}{1-p_w^k}} - p_w^{k-1} \sqrt{\frac{1-p_w^k}{p_w^k}} \]

很明显不关于点 (1/2, 0) 呈中心对称。

2. Pass@k 解析解的“无偏性” (Unbiased Expectation)

这里的“期望没有偏执”可以从两个层面理解，我将分别阐述。

层面一：作为估计器（Estimator）的无偏性

在统计学中，如果一个估计量的期望值等于被估计参数的真值，则称该估计量是无偏的。 * Bootstrap 采样法：它是一种蒙特卡洛估计。通过随机抽样 \(M\) 个组，计算出每个答案的平均优势。当 \(M \to \infty\) 时，这个估计值会收敛到其期望值。对于有限的 \(M\)，它是一个有偏（由于非线性）或高方差的估计。 * 解析解法：解析解不是一个估计器，它直接计算了在 Bootstrap 采样框架下，一个答案的数学期望（Expected Value）。它绕过了采样的过程，直接得到了那个当 \(M \to \infty\) 时的收敛目标。

因此，说解析解是“无偏的”是正确的，甚至可以说它比无偏更强——它是零方差的精确解。它完美地计算了我们想要的目标（一个答案在所有可能分组下的期望优势），没有任何由随机采样引入的误差或偏差。

层面二：策略的期望优势是否为零

在某些强化学习理论推导中，一个重要的性质是策略的期望优势 \(E_{a \sim \pi}[A(a)]\) 为零。这保证了在当前策略下，所有行为的优势加权平均为零。我们来验证一下。

  • 对于 Pass@1： \[E[A] = p \cdot A_p + (1-p) \cdot A_n = p \sqrt{\frac{1-p}{p}} + (1-p) \left(-\sqrt{\frac{p}{1-p}}\right) = \sqrt{p(1-p)} - \sqrt{(1-p)p} = 0\] Pass@1 满足此性质。

  • 对于 Pass@k： 策略的期望优势是： \[E[A] = \frac{N_p}{N} A_p + \frac{N_n}{N} A_n\] 将我们之前推导的 \(A_p\) 和 \(A_n\) 公式代入，经过一系列复杂的化简，会发现 \(E[A]\) 通常不为零。

但这不是一个问题。期望优势为零的性质在理论分析中很方便，但并非算法有效性的必要条件。RL 的核心是沿着优势指定的梯度方向更新策略，只要优势信号能够正确地指示哪些行为优于平均水平（这里的“平均水平”由 \(\mu_G\) 定义），优化就能正常进行。Pass@k 重新定义了奖励和优势的基准（从单个答案变为一组答案），因此其期望不为零是正常的。

结论：Pass@k 解析解作为“期望优势”的计算方法，是完全无偏且零方差的。而它计算出的优势值，其策略期望不为零，但这符合其算法设计，不影响其有效性。

3. Pass@k 解析解的“方差较大”问题

优势信号的方差 (Variance of the Advantage Signal Distribution) 这指的是在一次 rollout 中，所有 \(N\) 个答案获得的优势值 \(\{A_1, A_2, ..., A_N\}\) 这个集合本身的方差。这个方差反映了优势信号的“强度”或“区分度”。

  • 对于 Pass@1，其标准化优势的方差为： \[\text{Var}(A_{\text{Pass@1}}) = E[A^2] - (E[A])^2 = (p \cdot A_p^2 + (1-p) \cdot A_n^2) - 0^2\] \[\text{Var}(A_{\text{Pass@1}}) = p \left(\sqrt{\frac{1-p}{p}}\right)^2 + (1-p) \left(-\sqrt{\frac{p}{1-p}}\right)^2 = p \frac{1-p}{p} + (1-p) \frac{p}{1-p} = (1-p) + p = 1\] Pass@1 的标准化优势信号方差恒为 1。

  • 对于 Pass@k，其优势信号的方差为： \[\text{Var}(A_{\text{Pass@k}}) = \frac{N_p}{N} A_p^2 + \frac{N_n}{N} A_n^2 - (E[A])^2\] 这个表达式非常复杂，但我们不必精确计算它。通过观察论文图 9(b) 中的优势曲线，我们可以得出结论：

    • 在大多数情况下，Pass@k 的优势值 \(A_p\) 和 \(A_n\) 的绝对值都小于 Pass@1 的优势值。
    • Pass@1 的优势值可以非常极端（例如 \(p \to 0\) 时，\(A_p \to \infty\)），而 Pass@k 的优势值则被约束在一个更温和的范围内。

这意味着 Pass@k 的优势信号分布更集中，其方差通常小于 Pass@1。

结论：您的判断“方差较大”与事实恰好相反。Pass@k 解析解的估计器方差为零。其产生的优势信号方差通常更小。这并非缺点，而是其优点： * 更稳定的梯度：更小的优势值意味着更平滑的损失曲面和更稳定的梯度更新，避免了 Pass@1 中因个别失败（尤其是在高成功率时）而导致的剧烈惩罚。 * 更精细的信用分配：Pass@k 的优势信号更具信息量。一个错误答案的优势 \(A_n\) 不再是一个固定的负值，而是依赖于整体成功率 \(N_p/N\) 的函数。这种动态调整使得奖励信号更加 nuanced，能够区分“在困境中的探索性失败”和“在优势局下的愚蠢错误”，从而更好地指导探索。

总结

  1. 对称性：Pass@1 的优势函数不对称，惩罚和奖励的幅度随成功率变化。对称的是其总优化力度曲线。Pass@k 优势函数的不对称性是其核心优点，使其能聚焦于难题。
  2. 无偏性：Pass@k 解析解是其期望优势的精确、无偏、零方差计算，这是它相比随机采样法的根本优势。
  3. 方差：Pass@k 的优势信号分布的方差通常更小，这带来了更稳定、更精细的梯度信号，有效避免了 Pass@1 的“过度惩罚”问题，从而保护了有价值的探索行为。

希望这个详细的推导和分析能够澄清您的疑问。您的问题非常有价值，它迫使我们深入到算法的数学细节中，去理解其为何有效。

您提出的这个问题，精准地击中了这篇论文思想的最高点，并指向了 RLVR (Reinforcement Learning from Verifier Feedback) 的未来发展方向。

通过我们之前的探讨，我们已经明确： 1. Pass@k 训练的核心是通过一个与 \((N_n/N)^k = (1-p)^k\) 相关的概率，推导出其独特的优势函数 \(A(p)\)。 2. 调整 \(k\) 实际上是在一个预设的函数族（Pass@k family）中，选择一条特定的优势函数曲线，主要是通过移动优势峰值的位置来调整模型对难题的关注度。

您的提问是：这个由 Pass@k 定义的函数族就是最优的吗？我们能否设计出更好的函数？

答案是：几乎可以肯定，存在更好的函数。 Pass@k 的伟大贡献不在于它找到了那个唯一的“圣杯”函数，而在于它揭示了通过直接设计优势函数的形态来引导模型学习这一全新范式——即论文所说的“隐式奖励设计”。

下面，我将基于我们共同的探讨，提出几类我认为可能更优的函数，并阐述其背后的原理。

从设计奖励到设计“优势曲线”

传统思路是设计一个奖励函数 \(R\)，然后计算其对应的优势函数 \(A\)。新范式则是跳过 \(R\)，直接根据我们的优化目标来“绘制”我们想要的优势函数曲线 \(A(p)\)，其中 \(p\) 是 rollout 准确率。

一条“好”的优势曲线应该具备哪些可调节的特性？ 1. 峰值位置 (Argmax): 决定了模型将主要精力聚焦于哪个难度区间的问题。 2. 曲线偏度 (Skewness): 决定了对“简单题”和“困难题”的优化力度是否对称。 3. 衰减速度 (Decay Rate): 决定了模型多快会“放弃”对已掌握问题的优化，以避免过拟合。 4. 信号幅度 (Magnitude): 决定了整体的优化强度，可以看作是一种动态的学习率。

Pass@k 的函数族在调节峰值位置上表现出色，但在其他方面则缺乏灵活性。

更好的函数类别设想

类别一：参数化概率分布函数（如 Beta 分布）

这是最直接、最优雅的推广。Beta 分布的概率密度函数 (PDF) 是定义在区间 \[ 上的，这与我们的 rollout 准确率 $p$ 的定义域完美契合。其形式为： \]f(p; , ) = $$ 其中 \(B(\alpha, \beta)\) 是归一化常数。

我们可以直接将总优化力度 \(L(p) = p|A_p(p)| + (1-p)|A_n(p)|\) 设定为与 Beta 分布成正比。通过调节超参数 \(\alpha\) 和 \(\beta\)，我们可以极其灵活地控制优势曲线的形态：

  1. 模拟 Pass@1: 当 \(\alpha = \beta = 2\) 时，\(f(p; 2, 2) = 6p(1-p)\)，这是一个在 \(p=0.5\) 处达到峰值的对称抛物线，形态上与 Pass@1 的总优化力度曲线（见论文图 9(a)）非常相似。

  2. 模拟 Pass@k: 当 \(\alpha > 1, \beta > \alpha\) 时（例如 \(\alpha=2, \beta=5\)），峰值会出现在 \(p = (\alpha-1)/(\alpha+\beta-2) = 1/5 = 0.2\)，这就模拟了 Pass@k 关注难题（低准确率）的行为。

  3. 实现动态训练策略 (Curriculum Learning):

    • 训练初期 (Warm-up): 设置 \(\alpha > \beta\) (如 \(\alpha=5, \beta=2\))，将峰值推向高准确率区域（如 \(p=0.8\)）。这会鼓励模型先从它有把握解决的“简单题”入手，建立基础能力，这比一开始就啃硬骨头要高效。
    • 训练中期 (Exploration): 切换到 \(\alpha < \beta\) (如 \(\alpha=2, \beta=5\))，即 Pass@k 模式，鼓励模型攻克难题，进行广泛探索。
    • 训练后期 (Fine-tuning): 逐渐让 \(\alpha, \beta\) 趋近于 1，使得分布变得更平坦，对所有难度的问题进行“查漏补缺”式的优化，防止在某些问题上过拟合。

优势: Beta 分布为我们提供了一个理论完备且控制力极强的工具箱，让我们能够根据训练阶段的需求，任意“塑造”我们想要的优势景观。

类别二：熵引导的自适应函数 (Entropy-Guided Adaptive Function)

前面的方法都是基于宏观的 rollout 准确率 \(p\)。但对于模型来说，同样是 \(p=0.1\) 的两个不同问题，其内在状态可能是完全不同的。 * 问题 A (\(p=0.1\), 低熵): 模型非常“自信”地收敛到了一个错误的解法上，并且每次都生成类似的错误答案。这表明模型陷入了局部最优。 * 问题 B (\(p=0.1\), 高熵): 模型对解法毫无头绪，每次都生成完全不同的答案，处于混乱探索阶段。

一个更优的函数，应该是关于准确率 \(p\) 和策略熵 \(H\) 的二维函数 \(A(p, H)\)： \[A = f(p, H)\]

  1. 对于问题 A (低 \(p\)，低 \(H\)): 我们需要最强的探索信号。此时应采用类似 Pass@k 的优势函数，并且可以给予一个额外的“奖励”来惩罚低熵，鼓励模型跳出当前的舒适区。
  2. 对于问题 B (低 \(p\)，高 \(H\)): 我们需要最强的利用信号。此时应采用类似 Pass@1 的优势函数，其信号强度和区分度更高，能帮助模型从混乱中快速锁定任何偶然出现的正确信号。
  3. 对于已掌握的问题 (高 \(p\)，低 \(H\)): 优势信号应快速衰减至零，以节约计算资源并防止过拟合。

优势: 这种方法将宏观统计指标 (\(p\)) 与微观模型状态 (\(H\)) 相结合，实现了“一题一策”的精细化指导，是真正意义上的自适应学习。

类别三：分段线性/多项式函数 (Piecewise Polynomial Functions)

这是一种更偏工程实践、但同样有效的方法。我们可以手动设计一个分段函数来近似我们想要的任何曲线形态。例如，我们可以定义一个“关注极难问题”的优势函数： * 当 \(p \in [0, 0.1]\) (极难区): 使用一个陡峭的上升线性函数，给予最强的优化信号。 * 当 \(p \in [0.1, 0.4]\) (困难区): 使用一个平缓下降的函数。 * 当 \(p > 0.4\) (掌握区): 优势信号迅速衰减为零。

优势: 实现简单，计算开销极低，可解释性强。虽然不够“优雅”，但可以快速验证关于优势函数形态的各种假设。

总结

您的问题非常关键。Pass@k 的核心洞见在于：RLVR 的性能瓶颈不在于 PPO 算法本身，而在于驱动它的优势信号的设计。

  • Pass@k 是一个 brilliant 的起点，它用一个简单的分组思想，生成了一个非对称、关注难题的优势函数族。
  • 更好的函数必然存在。未来的研究方向，将不再是寻找另一个像 Pass@k 一样构思精巧的“奖励机制”，而是直接转向参数化、自适应的优势函数设计。

未来的 RLVR 训练框架，会有一个“优势函数模块”，研究者可以像选择学习率调度器一样，选择或自定义一个优势函数调度策略（例如，一个从 Beta(\(\alpha=5, \beta=2\)) 动态过渡到 Beta(\(\alpha=2, \beta=5\)) 的策略），从而将整个训练过程的探索与利用平衡，置于更加精确和动态的控制之下。
